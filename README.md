# 🎄 Merry Christmas Tree — Web Edition (Blazor WebAssembly)

Веб-версия интерактивной 3D-анимации рождественской ёлки, написанная на **C# (.NET 10)** и работающая прямо в браузере через **WebAssembly**.

---

## ✨ Особенности веб-версии

- **100% C# в браузере (Blazor WebAssembly Standalone)**:
  - Вся оригинальная математика 3D-рендеринга, Z-буфер, физика падающего снега и динамические сугробы работают на C# внутри браузера на клиенте без бэкенд-сервера.
- **Высокопроизводительный HTML5 Canvas рендеринг**:
  - Честные **60 FPS** через `requestAnimationFrame`.
  - Retina / HiDPI поддержка (`devicePixelRatio`) без замыливания символов.
  - Полноцветная палитра True Color.
- **Ретро CRT-эффект (Toggle)**:
  - Возможность включения сканирующих линий (scanlines) и неонового свечения (bloom).
- **Музыкальное сопровождение**:
  - Трек **Wham! — "Last Christmas"** (`Wham_Last_Christmas.mp3`) через браузерный HTML5 Audio / Web Audio.
  - Автоматический старт при первом клике пользователя (согласно политикам автоплея браузеров).
- **Двойное управление**:
  - Полная поддержка оригинальных горячих клавиш клавиатуры (`[Space]`, `[R]`, `[M]`, `[A]`/`[D]`, `[+]`/`[-]`, `[B]`, `[H]`).
  - Удобные интерактивные кнопки на экране для мыши и сенсорных экранов мобильных устройств.
  - Полноэкранный режим `[F]`.

## 🚀 Запуск локально

1. Убедитесь, что установлен [.NET 10 SDK](https://dotnet.microsoft.com/):
   ```bash
   dotnet --version
   ```

2. Перейдите в папку веб-проекта:
   ```bash
   cd MerryChristmasTree.Web
   ```

3. Запустите локальный сервер разработки:
   ```bash
   dotnet run --launch-profile http
   ```

4. Откройте в браузере:
   ```
   http://localhost:5296
   ```

## 📦 Сборка для бесплатного хостинга (GitHub Pages / Vercel / Netlify)

Так как проект является автономным (Standalone WebAssembly), его можно опубликовать как набор статических файлов (HTML + JS + WASM):

```bash
dotnet publish -c Release -o dist
```

Содержимое папки `dist/wwwroot` можно загрузить на любой статический хостинг (GitHub Pages, Cloudflare Pages, Vercel, Netlify или обычный Nginx/Apache).
